## Blend Modes blocker

The harness draws fixed-color public `Sprite(Texture.white)` instances at the same position into a transparent render texture: source `[210, 70, 140, 0.7]`, destination `[80, 160, 220]` with alpha 1 and 0.45. It records actual enum/alpha/background selection, reads a 1-pixel overlap sample, and compares linear premultiplied RGBA with the existing independent W3C reference at a tolerance of 5 bytes.

On Chromium WebGL2, Normal/Additive/Subtract/Screen agree within one byte, but Multiply and backdrop modes lose the source contribution (opaque destination reads approximately `[20, 90, 182, 255]`). On Chromium WebGPU, the advanced modes agree within tolerance, while Multiply remains wrong (`[6, 27, 54, 255]` versus `[15, 31, 88, 255]`; fractional destination alpha also differs). Both backend oracle files retain the actual and expected values. This is a red acceptance result, not a fallback or a waived test. Uniform-array caching was considered and rejected: WebGl2ShaderUniform.setValue copies and marks dirty on every call; WebGPU writes its blend buffer every composition. Core repair and any overlap with existing RenderTarget/Texture work require separate ownership.

An automatic approval review rejected lowering an earlier distinct-output assertion without evidence that its expectation was wrong. The assertion was kept, and the stronger fixed-color oracle above was added. No failing expectation was removed or baselined.

## Particle visual limit

Target 32's state/control checks pass on all three environments, including pause, cleared reset, rate/lifetime/speed and dragging. Its colored flame is not visually equivalent: WebGL2 shows a fine mosaic-like pattern while WebGPU renders soft textured particles. Both use the same explicit CPU simulation and the same awaited flame texture; the source and served texture SHA-256 are identical. Direct public ParticleSystem rendering retains the difference. This is a separate visual acceptance limitation, not a green parity claim or an engine repair in this batch. The force example's monochrome particle cloud does not establish colored-particle parity.
