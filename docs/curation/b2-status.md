## Remaining input blocker

`src/input/FocusController.ts:453` reads Shift from the final frame sample. In compact Chromium WebGL2 and WebGPU, a rapid `Shift+Tab` after the Take damage button wraps forward to Slider rather than backward to +10 score. The same keyboard workflow passes at desktop size and in Firefox. The failing assertion stays in `site/scripts/curation-b2-e2e.ts`; held-Shift success does not close this case. Core repair and the exact settings rerun belong to the separate integration strand.

## Migration and ownership

The main sources own their panels, UI, inputs and render nodes. #18 removes the global pointer-tap subscription, uses the scene-owned UI/action path, and tracks portrait/name/text/backdrop resources. Draft PR #866 remains open at `c7aaaabe9cafa6a5d545889ae8633c6c68726ffb`: its exact dialog hunk stores/removes a global `onPointerTap` callback and manually destroys namePlate, box and choicePrompt. This replacement collides with that hunk, implements scene ownership in the new structure, and copies no engine/shared fix.

All donor sources remain runnable: sprite-basics, custom-transition, pause-blur, hud-and-widgets and asset-catalogs. Central alias/catalog/guide work is owned by the integration slice. In particular, the old loading-screen global-loader-signal/application-claim/warm-cache narrative needs its dedicated guide fixture; the curated target now stays on the queue/retry screen. SourceSnippet region names are preserved. The basic path recommendation is #1 -> #2 -> #3 -> #5, with #4 an optional advanced ownership branch and #5 the section capstone; #16 -> #17 -> #18 is the UI continuation.
