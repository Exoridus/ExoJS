## Classification vocabulary

| Classification        | Meaning in this review                                                                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VALIDATED`           | The stated repository fact, artifact content, or CI outcome was directly checked. Validation of metadata or correctness does not validate current performance.   |
| `NEEDS_REMEASUREMENT` | Historical measurements exist, but their engine, workload, instrumentation, or acquisition conditions do not establish the current result.                       |
| `NOT_REPRODUCIBLE`    | The specified reconstruction cannot be performed from the inspected committed evidence alone. This does not assert that an original run never happened.          |
| `INCONCLUSIVE`        | The available evidence does not support the proposed conclusion, including an unstable comparison or a comparison between different instruments.                 |
| `REGRESSED`           | A qualified, comparable before/after acquisition establishes a regression under its stated conditions. No finding in this review receives this classification.   |
| `IMPROVED`            | A qualified, comparable before/after acquisition establishes an improvement under its stated conditions. No finding in this review receives this classification. |

## Roadmap ordered by evidence

### P1: qualify the measurement and workload contract

1. Preserve metric source end to end. Separate CPU duration, rAF cadence, hardware GPU execution, queue completion, and resource estimates. Reject missing/non-finite readings and partial-frame GPU coverage; never infer hardware timing from a field name.
2. Make asynchronous timer collection bounded and observable. Record valid, disjoint, unresolved, failed, and dropped samples; exercise cleanup and later-task readiness without introducing synchronization into the timed CPU bracket.
3. Close declared-work mismatches before timing. Qualify blend modes, masks, filters, geometry, text, visible work, canonical mutations, and native optimized paths. Retain an explicit unsupported result when equivalent work is not implemented.
4. Extend the existing plan and run identity rather than creating a competing one. Preserve exact engine revision, dependency and build inputs, acquisition order, sample counts, raw measurements, metric sources, environment observations, and partial-failure reasons. Keep old profiles distinct from new acquisitions.
5. Reconcile the pending resolver, Phaser lifecycle, and renderer-provenance drafts by their exact scopes and revalidate the integrated tree. Passing individual heads does not qualify their combination or a later change.

### P2: acquire current controlled evidence

Use the established independent-run procedure on a declared, idle reference machine after correctness qualification. Keep browser/backend/device identities, viewport/DPR, colour pipeline, workload, seed, build mode, and dependency versions fixed within a comparison. Preserve all outcomes, including unsupported, exceeded, unavailable, unstable, and timer-limited cells. Acquire matched before/after cells with the same session shape when testing an engine change.

Cover static reuse, mutation density, structural churn, hierarchy, visible/offscreen content, texture and material pressure, compositing, text, render targets, and application-shaped combinations at declared load points. Inspect scaling curves and tails before selecting an optimization. A high-count result is not automatically representative of common application loads, and an isolated microbenchmark is not a full-application result.

Report CPU and qualified GPU measurements separately, explain uncertainty, and preserve the costs of startup, setup, invalidation, and teardown when those are relevant to the claim. Do not replace the historical files or reset the timing baseline merely to obtain a favorable comparison.
